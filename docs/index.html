Press ⌘' and every clickable element gets a label. Type the label to click it.

Features

Click mode

Labels the buttons, links, menus, and menu bar items of the frontmost app.

Grid mode

Divides the screen into a grid and narrows it down in a few keys, so you can click any position even in apps that expose no clickable elements.

Scroll mode

Picks a scroll area and scrolls it with J K H L.

Mission Control

Shows labels on window thumbnails and spaces as soon as Mission Control opens.

Any input source

Labels are matched by key code, so they work while a Korean or other input method is active.

Your own look

Style click labels and the grid separately: characters, font, colors, padding, corner radius, or Liquid Glass.

Shortcuts

⌘'Click mode
⇧⌘'Grid mode
⇧⌘JScroll mode
⇧ + last characterRight-click
⌥ + last characterDouble-click
⌘ + last characterCommand-click
⌃ + last characterMove the cursor without clicking
